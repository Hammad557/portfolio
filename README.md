## ✨ Features

- **3D animated hero** built with Three.js
- Smooth scroll experience powered by **Lenis** and **GSAP** animations
- Fully responsive, single-page design — works on desktop and mobile
- Sections for About, FYP Project, Certifications, Skills, and Contact
- Working **contact form** (no backend needed — powered by FormSubmit, delivers straight to email)
- Dark, HUD-inspired visual style matching a cybersecurity/AI aesthetic

## 🚀 Featured Project — Final Year Project (FYP)

**AI-Based Vehicle Tracking & Monitoring System for Toll Plazas**

- Real-time vehicle detection, tracking, and counting using **YOLOv8** + **SORT/Kalman filter**
- Custom five-class vehicle dataset (Car, Van, Bus, Truck, Motorcycle)
- **Electron + Python WebSocket** architecture with a dark HUD-style UI
- Polygon ROI masking and configurable counting lines
- Packaged as a Windows installer (PyInstaller + electron-builder)
